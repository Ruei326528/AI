AI Agent 與拖拉式平台初探
AI Agent：可理解為能依照目標自主完成任務的人工智慧系統。除了大型語言模型之外，通常還會搭配提示詞、工具、記憶、知識庫與工作流程，使系統不只回答問題，也能執行任務並主動提供服務。
拖拉式開發：透過視覺化介面設定角色、模型、工具與流程，可以減少一開始撰寫大量程式碼的負擔，適合快速建立與測試 Agent 原型。
期末專題構想—OpenClaw 每日生活管家
發想來源：我之前曾經有試著用過OpenClaw，但是沒有做出什麼對生活有幫助的東西，因此想藉由這次課程更深入探索AI Agent能夠做到什麼事。並且，因為我本身比較常使用Discord，不太常看Mail，要一直上EECLASS注意公告、作業也很麻煩，所以想做一個會每天傳訊息體醒我的AI Agent。
Agent 定位：個人生活客服與主動提醒 Agent，不只等待使用者提問，也能在固定時間主動整理資訊並發送通知。
應用場景：大學生每天需要處理課程、作業、考試、行程及臨時事項，但資訊分散在不同平台，容易忘記截止日期。此 Agent 可接收自然語言指令、保存待辦事項，並透過 Discord 主動提醒。
功能規劃：
自然語言提醒：使用者可直接輸入「明天下午三點提醒我上傳 AI 報告」，Agent 會解析事件、日期與時間。
每日待辦摘要：每天早上整理當日課程、行程、作業與重要提醒。
分階段截止提醒：重要作業可在截止前 3 天、1 天及 2 小時分別通知。
週期性提醒：設定每天、每週或每月重複的生活事項。
校務資訊提醒：在取得使用者授權後，整理課程平台的新公告、作業及截止日期。
天氣與生活提醒：依天氣狀況提醒攜帶雨具、補充水分或調整衣物。
完成狀態追蹤：使用者可回覆完成、延後或取消，Agent 依回覆更新提醒狀態。
